This is the Oberon System originally from http://www.projectoberon.net/ and originally written in Oberon-07.

I used the version from https://github.com/rochus-keller/OberonSystem, particlularly the one with the
ObsExt backend, and made the code Micron compatible. 

The Screen module is used as a cross-platform human interface (the smae used for the Smalltalk example). 
The code works with all three backends: Qt, SDL and XCB. 


This example demonstrates that it is feasible to migrate Oberon projects to Micron and that the resulting
code can still look very similar to Oberon (upper-case keywords, semicolons, etc.).
